# LeetCode in Python

Python 3.9+ solutions to LeetCode problems, with problem descriptions and standard-library `unittest` tests.

- `easy/` — Easy problems.
- `medium/` — Medium problems.
- `hard/` — Hard problems.

Run all tests from the repository root:

```bash
python3 -m unittest discover -v
```

In PyCharm, open the repository, select a Python interpreter, and run the shared **All Tests** configuration. No additional dependencies are required.
